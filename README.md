# amateur-radio

This respository is for anyone who works ham radios and wants to get details of Transmitters and Repeaters, View SOTA logs graphically, view a dynamic version of the UK Bandplan, QRZ etc

This uses RGraph, HowToCreate Grid Utils and various other 3rd party applications. You will need to read their license agreements to ensure you are using them correctly.

You will need to place this in the folder structures specified using php 8.0 or above and MariaDB/MySQL. There is an SQL file that will need to but run on your SQL server to puild the tables in a database. You will also need to edit phpscripts/passwords.php with your database connection details and QRZ credentials.

This is provided for information only
